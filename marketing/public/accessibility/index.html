Accessibility · early-access commitments

Usable by more people, on purpose.

This page states Riot's accessibility commitments for the 1.0 early-access release and the exact rehearsal scope those commitments rest on. These are commitments under test, not audit results.

What we commit to

Commitments for the 1.0 early-access release.

Riot is community infrastructure; it fails its purpose if only some people can operate it. These commitments are recorded in the release source and gate the public release.

Core tasks, assistive technology first
  • Read your community newswire with VoiceOver (iPhone, iPad, Mac) and TalkBack (Android).
  • Create or join a community, and publish a signed update, using the same assistive technology.
  • Full keyboard operation on Mac, with a visible focus and no focus traps.
Presentation
  • Text scales with system text-size settings without breaking layouts.
  • Color is never the only carrier of meaning; claims appear as text.
  • Contrast meets at least 4.5:1 for text in app surfaces and store materials.
  • Reduced-motion settings are respected on this site and in app surfaces that animate.

Rehearsal scope — what the commitments rest on

Every device class. Every core task. Recorded.

Before the public release, each core task is rehearsed with assistive technology on every device class Riot ships on, against the exact store build. Results are recorded as release evidence; a failed rehearsal blocks the release rather than being explained away.

Device classes
  • iPhone and iPad with VoiceOver.
  • Mac with VoiceOver and full keyboard.
  • Android phone and Android tablet with TalkBack.
Core tasks per device
  • Read: open the app and read your community newswire.
  • Create: create or join a community.
  • Publish: publish a signed update to your community.

Honest boundaries

What this page is not.

Version 1.0 is an early-access release. Accessibility work continues after release, and early builds will have rough edges we have not found yet.

  • This page is not an audit result, a VPAT, or a conformance claim to any formal standard.
  • The rehearsal scope covers the core tasks above; edge surfaces may lag behind.
  • If you hit an accessibility barrier, report it through the support channel — accessibility reports are treated as release-blocking defects, not feature requests.

Riot is free, with no in-app purchases. See the releases page for the current build and the privacy page for the data posture.
